- [x] Maven + стандартная структура src/main и src/test.
- [x] Клиент, сервер, отдельные сеансы и маршрутизация.
- [x] RSA-OAEP, AES-GCM, проверка fingerprint, защита от повтора.
- [x] Работающий консольный интерфейс и автоматическая демонстрация.
- [x] Более 10 проверок JUnit 5.
- [x] README, правила исключения секретов, MIT LICENSE.
- [x] Настройки запуска VS Code и конфигурация CI.
- [x] Проверен живой консольный чат в трёх отдельных процессах и выход через `/quit`.
