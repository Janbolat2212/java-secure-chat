# Результаты проверки

Дата: 19.11.2026. Windows, Temurin JDK 21.0.13, Maven 3.9.11, JUnit 5.13.4.
Команда: `mvnw.cmd -B -ntp verify`.

| Набор | Проверок | Ошибок | Пропущено |
|---|---:|---:|---:|
| CryptoServiceTest | 18 | 0 | 0 |
| ProtocolTest | 14 | 0 | 0 |
| ChatIntegrationTest | 12 | 0 | 0 |
| Всего | **44** | **0** | **0** |

Параметризованные случаи JUnit считаются отдельными выполненными проверками.

Проверяются:
- точное восстановление английского, русского, казахского текста, emoji и длинных сообщений;
- неверный AES/RSA-ключ, изменённые шифротекст, IV, тег, адресат и направление;
- RSA-OAEP, кодирование ключей и доверенный/неверный fingerprint;
- ограничение размера, обрезанный пакет, некорректный UTF-8, имена и пустой текст;
- реальный чат через loopback TCP в обе стороны, порядок сообщений и одновременные отправители;
- занятые имена, отсутствующий получатель и остановка сервера;
- реальные сетевые пакеты с изменённым тегом, повтором и неверным порядком.

Криптографический примитив допускает пустой массив, но пользовательский чат отклоняет пустое сообщение.
Тесты ошибок намеренно вызывают сообщения об отклонении соединений.
Демонстрация `java -jar target/secure-chat.jar demo` дополнительно проверяет собранный JAR.
Её фактический UTF-8 вывод сохранён в [demo-output.txt](demo-output.txt).
Дополнительно проверены три отдельных процесса: сервер, Alice и Bob. Сообщения
«Сәлем, Қазақстан! 🔐» и «Привет, получено!» доставлены без изменения,
оба клиента завершились через `/quit` с кодом 0.

Границы проверки: локальный Windows-компьютер. Запуск между двумя физическими компьютерами
и удалённый GitHub Actions ещё требуют отдельной проверки. Проект не проходил независимый аудит безопасности.
